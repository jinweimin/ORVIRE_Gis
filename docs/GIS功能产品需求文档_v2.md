---

## 1. 产品定位

### 1.1 差异化定位

| 维度 | 竞品现状 | 我们的方案 |
|------|----------|-----------|
| **交互范式** | 传统菜单驱动，操作路径深 | 命令面板（⌘K）+ 快捷键优先，类 IDE 体验 |
| **视图模式** | 单一 2D 地图 | 2D/3D 联动 + 纵断面剖面图 + 横断面视图 |
| **分析能力** | 基础查询分组 | 网络追踪（上下游）+ 缓冲区分析 + 连通性分析 |
| **智能化** | 手动编码缺陷 | AI 辅助缺陷识别 + 智能搜索（自然语言） |
| **时序能力** | 静态快照 | 时间轴回放 + 多期检测对比 |
| **协作** | 单机离线 | 标注批注 + 审核工作流 + 云端同步 |
| **信息密度** | 属性面板平铺 | 仪表盘叠加层 + 内联信息卡 |

### 1.2 设计原则

1. **键盘优先**：所有高频操作均可通过键盘完成
2. **空间直觉**：地图即画布，编辑即绘制
3. **渐进披露**：默认简洁，高级功能按需展开
4. **实时反馈**：操作 < 100ms 响应，无模态阻断
5. **上下文感知**：根据选中对象智能推荐操作

## 3. 核心功能模块

### 3.1 命令面板（Command Palette）

**设计理念**：借鉴 VS Code / ArcGIS Pro 的命令搜索，将所有功能扁平化为可搜索的命令列表。

| 特性 | 说明 |
|------|------|
| 快捷键 | `Ctrl+K` 或 `Space` 唤起 |
| 模糊搜索 | 支持拼音、首字母、中文、英文混合搜索 |
| 最近命令 | 记录最近使用的 10 个命令 |
| 上下文感知 | 根据当前选中对象过滤可用命令 |
| 快捷键提示 | 每个命令旁显示对应快捷键 |

**命令分类**：
- `>` 前缀：执行命令（如 `> 缩放至全图`）
- `#` 前缀：搜索图层（如 `# 检查井`）
- `:` 前缀：跳转坐标（如 `: 585538, 220874`）
- `?` 前缀：搜索帮助文档

---

### 3.2 多视图联动

#### 3.2.1 视图模式

| 模式 | 说明 | 场景 |
|------|------|------|
| **2D 地图** | 传统平面视图 | 日常浏览、编辑 |
| **3D 透视** | 三维地下管网视图 | 空间关系理解、汇报展示 |
| **纵断面** | 沿管段的纵向剖面图 | 坡度分析、埋深校核 |
| **横断面** | 垂直于管段的截面图 | 管径校核、碰撞检测 |
| **分屏** | 任意两种视图并排 | 对比分析 |

#### 3.2.2 视图联动

- 2D ↔ 3D 同步缩放/平移/选中
- 在 2D 地图上框选 → 3D 视图同步高亮
- 纵断面图中点击 → 2D 地图定位到对应位置
- 所有视图共享同一套图层控制

#### 3.2.3 纵断面图（Profile View）

参考 ArcGIS Pro Utility Network 的纵断面分析：

```
地面高程 ▲
         │    ╲         ╱
         │     ╲       ╱
         │      ╲     ╱
         │       ╲   ╱
         ├────────╲─╱────────→ 距离
         │    ┌────┐    ┌────┐
         │    │管道│    │管道│
         │    └────┘    └────┘
         │  MH-001   MH-002   MH-003
```

- 显示地面高程线、管底高程线、管顶高程线
- 标注检查井位置、管径、坡度
- 支持缩放、平移、测量
- 点击管段在纵断面中高亮 → 2D 地图同步定位

### 3.3 网络分析

#### 3.3.1 上下游追踪

| 功能 | 说明 |
|------|------|
| **上游追踪** | 从选中节点向上游追溯所有汇入管段 |
| **下游追踪** | 从选中节点向下游追溯所有流出管段 |
| **全路径追踪** | 显示从起点到终点的完整路径 |
| **追踪深度** | 可限制追踪的层级数 |
| **追踪结果** | 高亮显示 + 统计汇总（总长度、管段数、检查井数） |

#### 3.3.2 连通性分析

- 判断两个节点之间是否存在连通路径
- 查找孤立管段（未连接到主管网的管段）
- 环路检测

#### 3.3.3 爆管分析

- 模拟某管段爆管后的影响范围
- 自动识别需要关闭的阀门
- 计算受影响的用户数

#### 3.3.4 缓冲区分析

- 以管段/检查井为中心创建缓冲区
- 分析缓冲区内的建筑物、道路、其他管线
- 支持多级缓冲（如 5m / 10m / 20m）

---

### 3.4 智能搜索

#### 3.4.1 自然语言搜索

支持类自然语言的搜索表达式：

| 输入 | 解析结果 |
|------|----------|
| `DN400` | 搜索所有管径为 400mm 的管段 |
| `HDPE 材质` | 搜索所有 HDPE 材质的管段 |
| `2018年建造` | 搜索 2018 年建造的管段 |
| `有缺陷` | 搜索所有有缺陷记录的管段 |
| `DN400 HDPE 有缺陷` | 组合条件搜索 |
| `MH-001 上游` | 追踪 MH-001 的上游管段 |
| `最近30天检测` | 搜索最近 30 天内检测的管段 |

#### 3.4.2 搜索结果

- 结果列表 + 地图高亮联动
- 支持结果排序（按距离、按属性）
- 支持二次筛选
- 结果可导出或创建为新图层

---

### 3.5 时间轴与多期对比

#### 3.5.1 时间轴

- 底部时间轴控件，支持拖拽选择时间点
- 按检测日期过滤显示管段/检查井
- 支持播放模式：自动按时间顺序高亮显示

#### 3.5.2 多期对比

- 选择两个时间点，对比同一管段的变化
- 变化内容：缺陷等级变化、属性修改、新增/删除
- 差异高亮显示（红色=恶化、绿色=改善、黄色=修改）

---

### 3.6 AI 辅助功能

#### 3.6.1 AI 缺陷识别

- 集成 AI 模型，对 CCTV 检测视频进行自动缺陷编码
- 支持 NASSCO PACP / 国标 CJJ 181 编码体系
- 识别结果可人工复核确认
- 置信度显示，低置信度自动标记待复核

#### 3.6.2 智能推荐

- 选中管段后，AI 根据属性推荐可能的操作
  - "该管段已使用 15 年，建议安排 CCTV 检测"
  - "该区域管段缺陷率较高，建议生成热力图分析"
  - "检测到孤立管段，是否进行连通性检查？"

#### 3.6.3 智能报告

- 一键生成检测报告（Word/PDF）
- AI 自动提取关键信息并生成摘要
- 支持自定义报告模板

### 3.8 内联地图编辑

#### 3.8.1 直接编辑

- 双击地图上的管段/检查井，直接进入编辑模式
- 拖拽节点修改几何形状
- 右侧面板实时显示编辑中的属性
- 支持撤销/重做（Ctrl+Z / Ctrl+Shift+Z）

#### 3.8.2 智能捕捉

- 绘制新管段时自动捕捉到最近的检查井
- 显示捕捉参考线和距离
- 支持正交模式（水平/垂直锁定）

#### 3.8.3 批量编辑

- 框选多个对象 → 批量修改属性
- 支持表达式计算（如"将所有 DN300 管段的管径改为 DN400"）

---

### 3.9 热力图与空间可视化

#### 3.9.1 缺陷密度热力图

- 以管段缺陷密度为权重生成热力图
- 颜色方案可自定义（红-黄-绿 / 紫-橙-黄）
- 支持调节半径和衰减参数

#### 3.9.2 管龄分布图

- 按建造年份渐变着色
- 可视化管网老化程度

#### 3.9.3 流向动画

- 管段上显示流动方向的动画粒子
- 流速可按管径/坡度模拟

---

### 3.10 标注与协作

#### 3.10.1 地图标注

- 在地图上添加文字标注、箭头、矩形框、自由绘制
- 标注可绑定到特定对象（跟随移动）
- 支持标注图层的显示/隐藏

#### 3.10.2 审核批注

- 对检测结果添加审核意见
- 支持 @ 提及团队成员
- 批注状态：待审核 / 已通过 / 需修改

#### 3.10.3 变更追踪

- 记录所有数据修改的历史
- 支持查看"谁在什么时候修改了什么"
- 可回滚到任意历史版本

---

## 7. 性能要求

| 指标 | 要求 | 测试条件 |
|------|------|----------|
| 首屏渲染 | < 1.5s | 10 万要素图层 |
| 缩放/平移 | < 50ms | 连续操作 |
| 命令面板响应 | < 30ms | 输入即搜索 |
| 网络追踪 | < 500ms | 万级节点网络 |
| AI 缺陷识别 | < 3s/帧 | 单帧 CCTV 图像 |
| 内存占用 | < 800MB | 常态运行 |
| 撤销步数 | ≥ 50 步 | 内存限制内 |
